# ADR 0005 — Render e Supabase como plataforma primária da V2

**Status:** substituída pelo ADR 0006
**Data:** 21/08/2026

## Registro histórico

Este ADR substituiu a seleção inicial de infraestrutura e estabeleceu Render, Supabase e GitHub Actions como direção do piloto. A revisão de 08/09/2026 consolidou a restrição de não contratar grandes nuvens e definiu os requisitos de recuperação, TLS e separação de responsabilidades no [ADR 0006](0006-fractionated-platform.md).

Render e Supabase continuam candidatos iniciais, mas a decisão vigente é o ADR 0006. Não usar este arquivo como procedimento de provisionamento.
