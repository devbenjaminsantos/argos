# ADR 0002 — Azure como plataforma da V2

**Status:** substituída pelo ADR 0005
**Data:** 16/07/2026

## Registro histórico

Esta foi a seleção inicial de plataforma, substituída em 21/08/2026 pelo ADR 0005. Em 08/09/2026, o [ADR 0006](0006-fractionated-platform.md) passou a proibir Azure e demais grandes nuvens como destinos contratados pelo Argos.

O conteúdo operacional foi removido para impedir provisionamento acidental. Os princípios que permanecem válidos — processo API separado do job, armazenamento externo ao contêiner, segredos fora do repositório e execução idempotente — estão registrados nos ADRs 0001 e 0006.
