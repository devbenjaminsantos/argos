# Registro histórico da avaliação Azure

**Status:** arquivado em 08/09/2026.

A Azure foi avaliada antes da definição da plataforma fracionada. Nenhum serviço de aplicação ou banco do Argos foi provisionado nesse provedor.

O projeto não usará Azure como destino contratado. Esta página não contém procedimento operacional, credenciais, recursos ativos ou próximos passos. A decisão vigente está no [ADR 0006](decisions/0006-fractionated-platform.md).
